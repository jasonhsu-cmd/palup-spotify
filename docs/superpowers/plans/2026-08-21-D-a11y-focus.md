# Accessibility — Focus Management (Workstream D) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop stranding keyboard/screen-reader focus. Closing the panel returns focus to the launcher; editing the cart keeps focus on the item; the mobile full-screen panel traps focus; product names are headings.

**Architecture:** Three files: `loader-core.ts` (close-focus + mobile `inert`), `storefront/app.js` (cart focus restore + `<h3>` titles), and a manual screen-reader verification pass (these are behavioral; automated tools score 100 and miss them). The nested-live-region item is DEFERRED until the SR pass confirms it — do not change consent-card ARIA blindly.

**Tech Stack:** TypeScript (loader), vanilla JS (storefront), Vitest (loader unit), Playwright (E2E), + manual NVDA/VoiceOver. `env -u GOOGLE_CLOUD_PROJECT`.

**Spec:** `docs/superpowers/specs/2026-08-21-ux-review-remediation-program-design.md` (Workstream D).

## Global Constraints
- **No §3 surface, no consent-logic change.** ARIA/focus only.
- **Contrast is already AA — do not touch color.**
- The loader owns the *real* launcher; only `loader-core.ts` can restore focus to it (the panel iframe cannot reach it).
- Non-§3, auto-merge on green — BUT the manual SR pass (Task 5) must be done before calling this workstream complete.

### Task 2: Mobile full-screen panel inerts the host content

**Files:**
- Modify: `packages/widget/src/loader-core.ts` (`open()` `:193-206`, `close()` `:208-211`)
- Test: `packages/widget/test/loader-core.test.ts`

**Interfaces:** on a small viewport (`matchMedia("(max-width:480px)").matches`), `open()` sets `inert` on every direct child of `document.body` except the loader's mount container; `close()` clears it. Non-mobile: no-op.

- [ ] **Step 1: Write the failing test** (mock `matchMedia` to match; assert a sibling body child gets `inert` on open and loses it on close):
```ts
it("inerts host content while the mobile panel is open", () => {
  (window as any).matchMedia = () => ({ matches: true, addEventListener() {}, removeEventListener() {} });
  const sibling = document.createElement("div"); document.body.appendChild(sibling);
  const c = cfg(); const api = initWidgetLoader(c);
  api.open();
  expect(sibling.hasAttribute("inert")).toBe(true);
  api.close();
  expect(sibling.hasAttribute("inert")).toBe(false);
});
```

- [ ] **Step 2: Run it, verify it fails.**

- [ ] **Step 3: Implement** — add a helper and call it from `open`/`close`:
```ts
function setHostInert(on: boolean): void {
  try {
    if (!window.matchMedia || !window.matchMedia("(max-width:480px)").matches) return;
    const mount = root instanceof ShadowRoot ? root.host : root; // the loader's own element
    for (const child of Array.from(document.body.children)) {
      if (child === mount) continue;
      if (on) child.setAttribute("inert", ""); else child.removeAttribute("inert");
    }
  } catch { /* best-effort */ }
}
```
Call `setHostInert(true)` at the end of `open()` and `setHostInert(false)` at the end of `close()`. (Confirm `root`/`mount` is the loader's body-level container; adjust the `mount` derivation if the loader mounts differently.)

- [ ] **Step 4: Run it, verify it passes. Commit** — `git commit -am "fix(widget): trap focus by inerting host content behind the mobile panel"`


- [ ] **Step 2: Run `pnpm e2e:storefront-catalog`, verify it fails** (focus drops to BODY).

- [ ] **Step 3: Implement.** Give `renderCart` an optional `focusHint` ({ productId, kind: "inc"|"dec"|"remove" }); the dec/inc/remove handlers pass their own hint; after the list is rebuilt, if a matching control exists, `.focus()` it, else focus the cart heading. Minimal shape:
```js
function renderCart(focusHint) { /* … rebuild … */
  // after mount.appendChild(list):
  if (focusHint) {
    var sel = '[data-pid="' + CSS.escape(focusHint.productId) + '"] [data-role="' + focusHint.kind + '"]';
    var target = mount.querySelector(sel) || mount.querySelector('.cart-row [data-role="remove"]') || document.querySelector("h1");
    if (target && target.focus) target.focus();
  }
}
```
